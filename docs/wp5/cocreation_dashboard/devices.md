# Compatible devices

A number of devices were tested with the Co-Creation platform software:

- The HDK Mark II Kit from Actronika for haptic output.
- The H10 Polar chest strap for sensory input.
- The Unicorn EKG cap for EKG sensory input.

However, most devices (as long as proper modulation for inside the audio stream can be found) can be made compatible, based on demand.
